Train panels explore and learn; test panels play their held-out maps greedily with the same network and never learn.

Maps

Held-out = test levels whose map is not in training (a level on a training map is struck through).

Data augmentation

Mirror: the rim's cyclic order reversed, same labels (a different input for the priors GNN, the same input for the tabula-rasa net). Splice variants: single edge flips / vertex insertions / removals of the training maps that keep states 3+ swaps deep, each with its whole state space, walked by 2 unseen mice that start in the deepest states. The big hard pool (thousands of evolved maps) is built by tools/arena_hardgen.js for headless training. Applies on Reset.

Network params –

Priors GNN: rim-relative colours, degree, rim position and per-chain features in; h' = relu(Ws h + Wn mean(nbrs) + b), K rounds; readout mean, max, 5 rim and hole embeddings. Applies on Reset.

Tabula rasa: raw colour one-hots and the hole flag only (colour symmetry learned from random colour permutations); one weight-tied layer h = tanh(Ws h + Wn Σnbrs/6 + Wx x + b) iterated T times; heads: afterstate value and "click a region, pick a colour". Slow in a browser tab: the strong ones are trained with tools/arena_scale.js. Applies on Reset.

RL afterstate TD, live

Reward −1 per swap, 0 at a fill. A swap is scored −1 + γ·V(the colouring it leads to). Aux = masked-colour + chain-size losses on replay states.

Pretrain random maps, then RL

(a) distance to a fill, (b) good swap (lowers the exact distance), (c) masked colour, (d) chain size and rim reach with chain inputs hidden. Exact labels by BFS over each small map's Kempe class (n ≤ 26). Then V starts as −distance and RL fine-tunes.
